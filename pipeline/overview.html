데이터가 잘 도착하고 있나요?

복잡한 로그 대신, 수집 결과와 저장된 내용을 그래프로 확인하세요.

생성·전송 실험실로 이동 →

실제 MongoDB 저장 데이터와 API 전송 기록을 사용합니다. 이 페이지는 조회 전용이며 데이터를 만들거나 바꾸지 않습니다.

연결하면 3초마다 새로 확인합니다.
보낸 요청—재전송 포함
접수된 요청—서버가 받아들인 요청
걸러낸 요청—인증·규격이 맞지 않은 요청
중복 제거 후 행동—분석에 사용하는 학습 기록

지금 상태 연결 대기

실험을 선택하면 결과를 설명해 드립니다.

① 보낸 요청은 어떻게 됐나요?

이 그래프는 전체 요청을 한 번씩만 셉니다.

0전체 요청
테스트에는 일부러 잘못 만든 요청도 포함됩니다. 예상한 거부 응답이면 정상적인 방어 동작입니다.

② 데이터는 어디에 저장됐나요?

각 저장함의 문서 수입니다. 서로 겹칠 수 있어 합산하지 않습니다.

원본은 재전송도 보존합니다. 학습 기록은 중복을 제거하며, 종료 기록은 실행 기록에도 들어갑니다.

③ 어떤 학습 행동이 있었나요?

중복을 제거한 행동 기록을 종류별로 셉니다.

문제 시작·조작·힌트는 행동입니다. 학습 실패는 명시적인 ‘시도 실패’ 기록만으로 계산합니다.

④ 게임은 어떻게 종료됐나요?

이번 실험에서 생성한 모의 종료 기록입니다.

멈춤·통신 단절 의심은 확정 장애가 아닙니다. 이 값은 실제 게임의 장애율이나 사용자 이탈률을 뜻하지 않습니다.

⑤ 따로 보관한 데이터

같은 이벤트 번호로 내용이 달라진 기록 등, 바로 분석에 쓰면 안 되는 데이터를 분리합니다.

API에서 거부한 요청과는 다릅니다. 여기서는 접수 후 처리 과정에서 격리한 기록만 보여줍니다.

그래프는 선택한 더미 실험 한 건의 결과입니다. 과거 완료 실험을 선택하면 고정된 결과를, 진행 중 실험을 선택하면 증가하는 건수를 볼 수 있습니다.
관측 시점에 따라 처리 중 데이터가 잠시 차이 날 수 있습니다. 수집 시스템 전체 성능이나 실제 사용자 행동을 대표하지 않습니다.
